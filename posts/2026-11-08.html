오늘의 영어표현 10

2026년 11월 8일 · 일요일

🔊 아이콘을 누르면 발음을 들을 수 있어요 — 소리 내어 따라 읽어보세요

회사 표현 5개 일상 회화 표현 5개
회사에서 쓰는 표현
Let's freeze the code
코드를 동결합시다 (릴리스 직전에 변경을 멈출 때)
AAre we still merging features?
BLet's freeze the code on Thursday and only fix bugs.
It's working on my machine
제 컴퓨터에서는 되는데요 (재현이 안 되는 버그를 말할 때)
AThe page crashes on startup.
BIt's working on my machine. Can you send me the logs?
Let's break this down into tasks
이걸 작업 단위로 쪼갭시다 (큰 일을 나눌 때)
AThis feature feels huge.
BLet's break this down into tasks and estimate each one.
We need to roll back the release
릴리스를 롤백해야 해요 (배포 후 문제가 생겼을 때)
AError rates doubled after the deploy.
BWe need to roll back the release right now.
Let's keep the PR small
PR을 작게 유지합시다 (리뷰하기 쉽게 만들 때)
AMy pull request has fifty files.
BLet's keep the PR small so it's easier to review.
일상 회화 표현
I'm running late
저 늦을 것 같아요 (약속에 늦을 때)
AWhere are you? The movie starts soon.
BI'm running late. Please save me a seat.
It slipped my mind
깜빡했어요 (잊어버렸을 때)
ADid you call the dentist?
BSorry, it slipped my mind. I'll call now.
Let's catch up soon
조만간 만나서 얘기해요 (오랜만에 만난 사람과 헤어질 때)
AIt was great seeing you after so long!
BSame here. Let's catch up soon over coffee.
I'm on a tight budget
예산이 빠듯해요 (돈이 넉넉하지 않을 때)
ADo you want to go to that fancy place?
BI'm on a tight budget this month. Can we pick somewhere cheaper?
I couldn't agree more
전적으로 동감이에요 (상대 의견에 크게 공감할 때)
AThis weather is perfect for a walk.
BI couldn't agree more. Let's go to the park.
