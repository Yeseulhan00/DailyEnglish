회사에서 쓰는 표현
Can we get an ETA on this?
이거 예상 완료 시점 좀 알 수 있을까 (작업이 언제 끝날지 일정을 미리 파악해서 계획을 세우고 싶을 때)
AThe client keeps asking when the migration will be finished.
BCan we get an ETA on this so I can give them something concrete?
Let's cache this response
이 응답을 캐싱하자 (같은 요청이 반복될 때마다 다시 계산하거나 조회하지 않도록 결과를 저장해두고 재사용하고 싶을 때)
AThis endpoint hits the database on every single request and it's really slow.
BLet's cache this response so we don't query the same data over and over.
Let's parallelize the build
빌드를 병렬로 처리하자 (빌드나 테스트에 시간이 너무 오래 걸릴 때 여러 작업을 동시에 실행해서 시간을 줄이고 싶을 때)
AOur CI pipeline takes almost forty minutes now, it's really slowing us down.
BLet's parallelize the build so the steps run at the same time instead of one by one.
Can we get consensus on this approach?
이 접근 방식에 대해 다 같이 합의를 볼 수 있을까 (팀원들의 의견이 갈릴 때 본격적으로 작업을 시작하기 전에 전체 동의를 이끌어내고 싶을 때)
AHalf the team wants to rewrite it and the other half wants to patch the old code.
BCan we get consensus on this approach before anyone commits more time to either side?
Let's add telemetry to this
여기에 텔레메트리를 추가하자 (운영 중인 시스템이 실제로 어떻게 동작하는지 데이터를 수집해서 문제를 더 빨리 파악하고 싶을 때)
AWe have no idea why this feature is slow for some users but not others.
BLet's add telemetry to this so we can actually see what's happening in production.
일상 회화 표현
I'm freezing
나 완전 얼어 죽겠어 (날씨가 너무 추워서 몸이 얼어붙을 것처럼 느껴질 때)
AWhy didn't you bring a jacket? It's freezing tonight.
BI know, I'm freezing, can we head inside somewhere?
I need a breather
나 잠깐 숨 좀 돌려야겠어 (일이나 상황에 지쳐서 잠깐이라도 쉬는 시간이 필요할 때)
AWe've been packing boxes non-stop for three hours straight.
BI need a breather, let's sit down for a few minutes first.
It's not worth the hassle
그건 번거로울 만한 가치가 없어 (들이는 수고나 노력에 비해 얻는 게 적어서 그냥 안 하는 게 낫다고 생각할 때)
AShould we try to get a refund for the ten-dollar difference?
BHonestly, it's not worth the hassle, let's just let it go.
I'm not falling for that
나 그거에 안 속아 (누군가 속이려 하거나 뻔한 수를 쓰는 걸 눈치챘을 때)
ACome on, if you lend me the money I'll definitely pay you back tomorrow.
BI'm not falling for that, you said the same thing last month.
Make yourself at home
편하게 있어 (손님을 집에 초대해서 편안하게 지내라고 말할 때)
ASorry the place is a bit messy, I wasn't expecting you so soon.
BDon't worry about it at all, just make yourself at home.
