회사에서 쓰는 표현
It's a leaky abstraction
추상화가 내부 구현을 완전히 감춰주지 못해서 세부 사항이 새어 나와 문제가 생겨 (라이브러리나 API를 쓰는데 내부 동작까지 알아야만 제대로 쓸 수 있을 때)
AThis caching library keeps causing weird bugs whenever the network is slow.
BYeah, it's a leaky abstraction, we end up dealing with the raw HTTP details anyway.
Let's add some guardrails
실수해도 큰 사고로 이어지지 않도록 안전장치를 마련하자 (위험한 작업을 자동화하거나 배포할 때 사람의 실수를 막을 장치가 필요할 때)
ASomeone accidentally dropped a production database table last week.
BLet's add some guardrails so a single command can't wipe out an entire table.
Can we get some headroom on this?
여유 용량을 좀 더 확보할 수 있을까 (서버나 시스템이 한계치에 가깝게 돌아가서 갑자기 부하가 몰리면 감당하기 힘들 때)
AThe servers are running at ninety percent capacity during peak hours.
BCan we get some headroom on this? We should scale up before the holiday sale.
Let's right-size this
규모를 지금 상황에 딱 맞게 조정하자 (팀 인원이나 서버 자원이 실제로 필요한 것보다 많거나 적을 때)
AWe're paying for ten servers but only using about three of them.
BLet's right-size this and cut the cluster down to what we actually need.
Let's do a chaos test
일부러 장애 상황을 만들어서 시스템이 잘 버티는지 확인해보자 (실제 장애가 나기 전에 시스템의 약점을 미리 찾고 싶을 때)
AWe've never actually tested what happens if one of the database nodes goes down.
BLet's do a chaos test this week and see how the system handles it.
일상 회화 표현
I lost track of time
뭔가에 집중하다 보니 시간이 가는 줄도 몰랐어 (재미있는 일이나 몰입되는 일을 하다가 생각보다 늦어졌을 때)
AIt's almost midnight, why are you still up?
BI lost track of time, I was so into this book I couldn't put it down.
I'm just going with the flow
특별한 계획 없이 상황에 맞춰서 편하게 지내고 있어 (딱히 정해진 일정 없이 그때그때 되는 대로 움직일 때)
AWhat's the plan for the trip, do you have an itinerary?
BNot really, I'm just going with the flow and seeing what happens each day.
I was caught off guard
전혀 예상하지 못해서 순간 당황했어 (갑작스러운 질문이나 상황에 놀라서 제대로 대처하지 못했을 때)
AYou looked really surprised when they asked about your salary expectations.
BI was caught off guard, I didn't think they'd bring it up so early.
Let's split the difference
서로 조금씩 양보해서 중간 지점에서 타협하자 (의견이나 가격 차이가 있을 때 서로 절충안을 찾고 싶을 때)
AI want thirty dollars for it, but you're only offering twenty.
BHow about we split the difference and settle on twenty-five?
I've got butterflies in my stomach
긴장돼서 속이 울렁거려 (중요한 발표나 면접 같은 걸 앞두고 떨릴 때)
AAre you nervous about the interview tomorrow?
BYeah, I've got butterflies in my stomach just thinking about it.
