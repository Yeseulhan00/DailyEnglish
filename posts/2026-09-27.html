회사에서 쓰는 표현
Let's version this API properly
이 API를 제대로 버전 관리하자 (API를 변경할 때 기존 사용자에게 영향을 주지 않도록 버전을 명확히 나눠서 관리하고 싶을 때)
AWe changed the response format and now the mobile app is crashing for old users.
BLet's version this API properly so old clients can keep using v1 while new ones move to v2.
Can we get a health check endpoint for this?
이거 헬스체크 엔드포인트 하나 만들 수 있을까 (서비스가 정상적으로 동작하는지 자동으로 확인해서 장애를 빨리 감지하고 싶을 때)
AThe load balancer has no way to know if this instance is actually healthy.
BCan we get a health check endpoint for this so it can automatically pull down bad instances?
It's idempotent
이건 몇 번을 실행해도 결과가 같아 (같은 요청을 여러 번 보내도 부작용 없이 항상 동일한 결과가 나오는 API나 함수를 설명할 때)
AI'm worried the retry logic might charge the customer twice if the request gets sent again.
BDon't worry, it's idempotent, so sending it multiple times won't create duplicate charges.
Let's refactor this before it gets worse
더 심해지기 전에 이거 리팩토링하자 (코드가 점점 복잡해지고 있어서 나중에 손대기 더 어려워지기 전에 미리 정리하고 싶을 때)
AThis function has grown to like three hundred lines and nobody wants to touch it anymore.
BLet's refactor this before it gets worse, otherwise it'll only get harder to maintain.
Can we get a linter rule for this?
이거에 대한 린트 규칙 하나 만들 수 있을까 (같은 실수가 코드 리뷰에서 반복적으로 발견돼서 자동으로 걸러내고 싶을 때)
AEvery single PR this week had the same unused import mistake.
BCan we get a linter rule for this so it gets flagged automatically before review?
일상 회화 표현
I'm pulling an all-nighter
나 오늘 밤새야 해 (마감이 급해서 잠을 안 자고 밤늦게까지 일이나 공부를 해야 할 때)
AYou look exhausted, did you even sleep last night?
BNot really, I'm pulling an all-nighter to finish this report by tomorrow morning.
It's a toss-up
그건 반반이야 (둘 중 어느 쪽이 더 나을지 확신이 안 서서 결과를 예측하기 어려울 때)
ADo you think we'll actually win this game tonight?
BHonestly, it's a toss-up, both teams have been playing really well lately.
Let's grab a coffee sometime
언제 커피 한잔하자 (오랜만에 만난 사람과 가볍게 시간 내서 이야기를 나누고 싶을 때)
AIt's been forever since we last caught up properly.
BI know, let's grab a coffee sometime this week if you're free.
I'm beside myself
나 정신이 하나도 없어 (너무 화가 나거나 걱정이 돼서 감정이 격해지고 평소처럼 침착하기 힘들 때)
AWhat happened? You look really upset right now.
BI'm beside myself, I just found out my flight got cancelled the night before the trip.
It's a done deal
이건 이미 확정된 거야 (계약이나 결정이 완전히 마무리돼서 더 이상 바뀔 가능성이 없을 때)
AIs there still a chance they might back out of the agreement?
BNo, it's a done deal, both sides already signed the contract this morning.
